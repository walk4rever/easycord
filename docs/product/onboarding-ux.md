## 2. 手势教学流程

### 步骤一：欢迎与权限

> **界面元素**
> 
> - 背景：半透明黑色遮罩
> - 中央：欢迎卡片 (白色圆角卡片)
> - 底部：摄像头预览画面（虚化）

> **卡片内容**
> 
> ```
> 🖐️ 欢迎使用 EasyCord
> 
> 我们将引导你学习 3 个简单的手势
> 来控制录屏
> 
> 整个过程只需要 1 分钟
> 
> [开始学习]  [跳过]
> ```

> **底部提示**
> 
> ℹ️ 需要摄像头权限来识别您的手势

---

### 步骤二：学习 "开始/暂停" 手势

> **界面元素**
> 
> - 左侧：手掌手势动画 + 说明文字
> - 右侧：实时摄像头预览 + 手部 Landmarks 叠加

> **说明文案**
> 
> ```
> 🖐️ 手掌 - 开始/暂停录制
> 
> 伸开手掌对着摄像头
> 系统会识别并显示绿色光圈
> 
> 再次伸出手掌即可暂停录制
> 
> [我知道了]  [上一个]  [下一个]
> ```

> **实时反馈**
> 
> - 识别到手掌：显示绿色光圈 + "✓ 手掌已识别"
> - 未识别：显示灰色光圈 + "请伸出手掌"

---

### 步骤三：学习 "标记精彩片段" 手势

> **界面元素**
> 
> - 左侧：V 手势动画 + 说明文字
> - 右侧：实时摄像头预览 + 手部 Landmarks 叠加

> **说明文案**
> 
> ```
> ✌️ V 手势 - 标记精彩片段
> 
> 在录制过程中比出 V 手势
> 系统会自动在当前位置添加标记
> 
> 方便后期快速定位重要时刻
> 
> [我知道了]  [上一个]  [下一个]
> ```

> **实时反馈**
> 
> - 识别到 V 手势：显示黄色标记 + "✓ V 手势已识别"
> - 未识别：显示灰色光圈 + "请比出 V 手势"

---

### 步骤四：学习 "保存" 手势

> **界面元素**
> 
> - 左侧：OK 手势动画 + 说明文字
> - 右侧：实时摄像头预览 + 手部 Landmarks 叠加

> **说明文案**
> 
> ```
> 👌 OK 手势 - 保存并退出
> 
> 录制完成后，比出 OK 手势
> 系统会自动保存视频并结束录制
> 
> 无需再寻找鼠标或点击按钮
> 
> [我知道了]  [上一个]  [下一个]
> ```

> **实时反馈**
> 
> - 识别到 OK 手势：显示蓝色对勾 + "✓ OK 手势已识别"
> - 未识别：显示灰色光圈 + "请比出 OK 手势"

---

### 步骤五：手势练习

> **界面元素**
> 
> - 中央：练习区域
> - 顶部：进度指示器 (3/3)
> - 底部：完成按钮

> **说明文案**
> 
> ```
> 🎯 来试试吧！
> 
> 请依次尝试以下手势：
> 1. 伸出手掌
> 2. 比出 V 手势
> 3. 比出 OK 手势
> 
> 已识别的手势会显示绿色光圈
> 
> [完成引导]
> ```

> **实时反馈**
> 
> - 三个手势都识别过：按钮变为可点击状态
> - 显示："太棒了！你已经掌握所有手势"

## 4. 首次使用提示 (Post-Onboarding)

### 免费版用户提示

当用户完成首次录制后：

> **弹窗提示**
> 
> ```
> 🎉 首次录制完成！
> 
> 你已完成第一次手势控制录屏
> 
> 当前使用免费版：
> ✓ 分辨率：720p
> ✓ 带有 "Powered by Air7.fun" 水印
> 
> [升级 Pro 解锁更多功能]
> [暂时不需要]
> ```

### 升级引导时机

| 时机 | 触发条件 | 引导内容 |
|------|----------|----------|
| **首次录制后** | 完成第一次录制 | 功能对比 + 限时优惠 |
| **尝试导出 4K** | 点击 4K 选项 | Pro 功能介绍 |
| **尝试移除水印** | 关闭水印选项 | Pro 功能介绍 |
| **使用 AI 功能** | 点击背景模糊 | AI 实验室介绍 |
