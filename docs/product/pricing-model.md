## 1. 定价策略概述

EasyCord 采用 **Freemium（免费增值）** 订阅模式，旨在通过免费版吸引用户试用，通过专业版功能解锁实现商业化变现。

### 核心定价原则

| 原则 | 说明 |
|------|------|
| **价值感知** | 免费版提供完整的基础功能，让用户感知产品核心价值 |
| **渐进式引导** | 通过免费版自然引导用户了解 Pro 功能 |
| **场景化升级** | 针对专业用户（内容创作者、企业）提供高价值功能 |

## 4. 定价心理锚点

### 免费版用户转化策略

```
免费版用户 ──(体验完整核心功能)──> 认知产品价值
                                              │
                                              ▼
                                    ┌─────────────────┐
                                    │  升级提示机制   │
                                    │ (录制完成后)   │
                                    └─────────────────┘
                                              │
                    ┌─────────────────────────┼─────────────────────────┐
                    │                         │                         │
                    ▼                         ▼                         ▼
           ┌────────────────┐       ┌────────────────┐       ┌────────────────┐
           │ 功能受限提醒   │       │ 场景化推荐     │       │ 限时优惠引导   │
           │ (4K/去水印)   │       │ (烹饪/健身场景)│       │ (首次付费 8 折) │
           └────────────────┘       └────────────────┘       └────────────────┘
```

### 升级触发点

| 场景 | 触发方式 |
|------|----------|
| 用户尝试导出 4K 视频 | 弹窗提示 "升级 Pro 解锁 4K" |
| 用户尝试移除水印 | 弹窗提示 "升级 Pro 移除水印" |
| 用户使用背景模糊 | 弹窗提示 "AI 实验室仅 Pro 可用" |
| 免费版云存储用尽 | 提示上传失败，引导升级 |
